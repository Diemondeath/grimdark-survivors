# Grimdark Survivors

Некоммерческий чиби-фан прототип 40K (Vampire Survivors × Binding of Isaac).

**Play:** [GitHub Pages](https://diemondeath.github.io/grimdark-survivors/) или открой `index.html` локально (`python3 -m http.server`).

**Управление:** стик слева / WASD, прыжок справа / Пробел.

## Floor 1 sprites
Целые спрайт-листы (idle/walk/attack/hit) для Культиста, Гибрида, Брута и Патриарха + спрайт Ультрамарина. Данные путей/скейла — в `data/sprites.js` и `data/enemies.js` (удобно для порта в Unity).

## Floor 2 sprites
Chaos: Хаосит (melee), Ренегат (ranged), Одержимый (elite), Демон-принц (boss). Paths in `data/sprites.js` / `data/enemies.js`.
